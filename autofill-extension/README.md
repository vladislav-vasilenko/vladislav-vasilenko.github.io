# Legacy Workday companion

Это отдельный старый инструмент для Workday, а не исполнитель задач локального Career Intelligence.

С версии 1.1.1 автоматическое внедрение и контекстное меню ограничены Workday. На Yandex, Sber, Ozon и Avito этот инструмент больше не предлагает независимое заполнение из публичного CV. Основной исполнитель этих сайтов — `tools/cv_matcher/hh-research-extension`, очередь и проверенные данные — локальный сервис `tools/cv_matcher`.

Старые Workday-функции сохранены: импорт опыта и образования, помощь с ответом через старый публичный endpoint. Они не используют выбранное локальное CV, approvals, Candidate Facts или CRM. Переносить их в основной workflow следует отдельным Workday-адаптером с preview, версиями и проверкой результата. До этого не считать два расширения взаимозаменяемыми.

См. [аудит структуры и причин](../tools/cv_matcher/docs/architecture/repository-and-autofill.md).
