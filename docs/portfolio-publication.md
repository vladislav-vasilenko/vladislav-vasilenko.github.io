# Public portfolio: local sources, publication and rendering

The local Career Intelligence service is the source of the reviewed public projection. SQLite, credentials, applications, internal Luna/Terra assessments, source documents and private notes stay local. GitHub Pages receives only the allowlisted `public/hh-experience.json`; Actions builds `dist/` without opening the local database.

## Sources and controls

Resume → **Портфолио · введение, опыт HH и GitHub** → **Предпросмотр и редактирование**.

- Title and work history come from the primary full HH resume selected in the local service. Source links point to that HH resume.
- Reviewed work-history translations are stored locally per target language and tied to the primary resume ID and a hash of all source experience blocks. They preserve row IDs, employers, dates and durations; changing the primary source disables stale translations. EN uses this translation of the primary RU history, never a different, older English HH resume. The editor is in the same publication preview and requires review before saving.
- The introduction defaults to HH “About”. A reviewed RU/EN portfolio draft can override it. A changed source invalidates the draft until reviewed again.
- Public visuals have a separate opt-in selector, trajectory, sample and JSON preview/download. Changes require owner review. Auto-publication checks every five minutes while the local service runs.
- “Current direction” publishes the generic track, up to five focus topics, public labs already checked through GitHub, and stage labels. It omits private goals, target companies, criteria notes and evidence identifiers.
- Confirmed practical skills require an owner-confirmed project/research/professional result with a public GitHub link. Studying is separate. Repository existence or activity does not prove authorship or proficiency.
- Market charts show an observed sample, grouped cosine coordinates rounded to 0.01 and category/completeness totals. The public alluvial diagram shows sample composition, not the personal application funnel. No vacancy/employer identifiers, CRM, raw quotations or detailed fit scores are published.

## PWA and offline behavior

Bilingual manifests share one app identity. Supported browsers offer installation; Safari users can add the page to the Home Screen. A build-versioned service worker caches only an explicit same-origin list of public pages, snapshot, compiled assets and icons. It does not intercept private localhost APIs, arbitrary resources, POST requests or database files. Public pages and snapshot use network-first with offline fallback. Updates are activated through a visible user action; a reading session is not forcibly reloaded.

Verification includes bilingual non-JavaScript rendering, title replacement, escaping, public projection privacy boundaries, totals, offline navigation, cache exclusions and icon sizes. Real phone hardware / every mobile browser is not covered by these automated checks.


The print toolbar offers both browser printing and a real PDF download. In installed standalone mode (including iOS `navigator.standalone`), its primary action generates a local PDF with embedded Roboto fonts for RU/EN; it does not rely on `window.print()`. A separate Save PDF action is also available in a regular browser. The PDF includes complete dated work history, introduction, education, skills/evidence and public contact links, omitting the phone number. Generation is lazy and runs entirely on the device, without a conversion service. PDF chunks are included in the explicit PWA cache list for subsequent offline use. Safari may open its PDF preview; use its Share controls to save or print. Real installed iOS hardware still requires verification. API reference: https://pdfmake.github.io/docs/getting-started/client-side/methods/ .

Mobile resume navigation is one compact row (language, labelled PDF shortcut, Appearance, overflow for Intro/Full CV). Style selection closes its picker and returns focus to the summary. The print CV uses a larger 150×190 px portrait (104×132 on narrow screens; 36×46 mm on paper); the PDF also embeds the public portrait. On mobile, each work-period line includes its duration inline with a middle-dot separator.

Playback keeps pointer scattering active: movement/touch velocity adds a bounded impulse over the flow field, while a stationary pointer does not prevent portrait settling. Horizontal touch gestures keep playback running; vertical intent yields to native scrolling. Flow trails sample one real representative cube per patch, and their newest endpoint is anchored to that cube every rendered frame instead of following patch averages.


## Molecular and cosmic exhibitions

Biology opens with DNA for seven visible idle seconds, then cycles Dopamine → Serotonin → Oxytocin → Adrenaline, seven seconds each, with a 1.6-second target morph. It never returns to DNA in that mount. The clock pauses during button playback, page hiding and resume reading. Molecules rotate continuously around their own long axes with slow precession and slight breathing. The source conformer remains intact; this is artistic motion rather than a molecular-dynamics solver.

Local heavy-atom coordinate and bond data live in `src/data/intro-molecules.json`; provenance is recorded in `src/data/README.md`. Dopamine, serotonin and adrenaline use PubChem computed conformers. Oxytocin uses RCSB PDB 7RYC chain L (including its terminal amide) and preserves its Cys1–Cys6 disulfide bridge. Hydrogens are omitted visually, while displayed formulas include them. Atom clusters and split-color single/double bonds reuse the original 1200 portrait instances. Simple molecules use 198–242 cubes; oxytocin uses 1080. Spares orbit in an eccentric, phase-shifted peripheral volume, accelerating near periapsis and drifting in depth, and join the next structure when needed. The captions localize names/formulas and explicitly identify the popular associations as pop-culture descriptions, with source links.

Cosmos first draws offscreen cubes into an accelerating 4.6-second accretion funnel, then distributes them into the solar system. The idle clock starts after this entrance and cycles Solar system (14 seconds) → Saturn (7 seconds) → Galaxy (21 seconds), with 1.6-second morphs. The Sun and eight orbiting planets use voxel surfaces, with eight orbital guides and an asteroid belt. Saturn has a flattened voxel body, a broad ring with a dark gap and four orbiting moons. Galaxy uses the revised irregular stellar disk. These are visual interpretations with arbitrary relative sizes and orbital times. Captions show only the structure name and concise identifying features.

After the supernova impulse, one 192-point additive draw call renders an expanding gas shell and two fading plumes aligned with the funnel normal. Procedural soft sprites dissipate after 2.8 simulation seconds and never cover the readable resume. During the noisy reassembly after the blast, each 4×4 portrait patch emits a synchronized, subtly colored pulse with golden-angle phase offsets between patches. Emission fades out as patches lock; the finished portrait keeps steady source-photo colors. Pulses have a slow 3.2-second period and bounded per-instance emission. They illustrate communication/attention, not measured transformer attention. There is no extra attention hold on the completed portrait; normal automatic and manual fall timing is preserved. Stop/reset clears this phase.
