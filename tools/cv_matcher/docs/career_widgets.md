# Панели на сайтах работодателей · 0.10.5

Поддерживаются список и страница вакансии на Яндексе (`yandex.ru/jobs`, `yandex.com/jobs`), Avito (`career.avito.com/vacancies`), Ozon.Tech (`ozon.tech/vacancies`), карьерном портале Ozon (`career.ozon.ru/.../vacancy`) и T-Bank (`tbank.ru/career`).

## Как включить

1. Обновите установленное расширение в `chrome://extensions`. Используйте папку `hh-research-extension` с версией **0.10.5**.
2. Запустите `resume_import_server.py`, подключите сервис и выберите полное CV и цель в расширении.
3. Откройте сайт работодателя; нажмите значок расширения → **3. Сбор → Показать разбор и письмо на сайте**.
4. Если описание ещё не сохранено, используйте сбор полных описаний либо откройте вакансию и нажмите **Сохранить открытую страницу в БД** в панели. Непроверенные семантические извлечения требуют подтверждения границ текста; они не становятся полными автоматически.
5. Нажмите **Разобрать** или **Сопроводительное письмо**, чтобы открыть результат рядом с вакансией. Открытие читает кэш; генерация начинается по отдельной кнопке. Либо выберите **Разбор навыков без API / Письмо без API**, скопируйте контекст в ChatGPT и верните результат в панель.

Один раз включённая панель восстанавливается при обычной перезагрузке в этой вкладке на том же домене. Для новой вкладки включение повторяется: используется `activeTab`, постоянных разрешений на все сайты нет. Это не автоматическое внедрение на каждую новую страницу браузера.

## Архитектура адаптеров

`board-adapters.js` содержит отдельные правила каждого источника: домены, страницы, контейнер карточки, заголовок и границы полного текста. Два портала Ozon имеют отдельные `board_id` и правила разметки; нормализованные ID вакансий у них совместимы. `board-core.js` и `src/board_import.py` согласуют идентичность вакансий между браузером и сервером. В текущей версии T-Bank также распознаёт ссылки `/career/back-office/vacancy/...`.

Общий движок `board-crawl.js` управляет лимитами, навигацией и сохранением; `board-content.js` применяет правила источника. `board-widget-core.js` размещает общую панель в границах одной вакансии. Формы работодателя, персональные поля и скрипты не входят в извлекаемое описание. Неизвестная структура остаётся `needs_review`, ограничение доступа останавливает обход. Для бесконечной ленты / «Показать ещё» собирается загруженная порция; пользователь загружает следующую. Автоматический полный обход таких лент ещё не реализован.

Панель переиспользует `/archive/hh-badges` и `/archive/hh-inline`; имена маршрутов сохранены для совместимости, они теперь принимают разрешённые источники. Чтение метаданных ограничено 100 ID одного источника. Ключ API и код сервиса остаются в worker / локальном сервисе. Неизменившиеся CV, вакансия и цель используют существующий разбор SQLite, включая импорт без API.

Письмо, вставленное вручную из ChatGPT, сохраняется с версиями в CRM, канал **Сайт компании (`career`)**. Он отделён от HH и Telegram. Подготовить / отправить такой отклик через очередь HH нельзя. Заполнение и отправка на сайте работодателя пока выполняются вручную; панель помогает анализировать и готовить текст.

## Проверено

- 159 тестов Python и 142 теста расширения проходят.
- Добавлены проверки экспорта / импорта разборов всех четырёх работодателей, повторного использования кэша без модели, сохранения писем и запрета ошибочной отправки через HH.
- Живые страницы списков Avito, Ozon.Tech, Яндекса и T-Bank прочитаны; публичные фрагменты карточек сохранены в `fixtures/boards` для регрессии. Исправлены заголовки T-Bank («Откликнуться» вместо профессии), внутренние `header` карточек и бейджи Ozon в названии.
- На реальной странице Ozon **Data Scientist, Анализ спроса** панель после обновления сервиса показала выбранное CV, «В базе» и четыре действия. Платная генерация и реальная отправка при проверке не выполнялись.
- Полная страница Avito прочитана и проверена на границы текста. Прямое открытие полного описания T-Bank при живой проверке завершилось сетевым таймаутом; универсальность его всех шаблонов этим тестом не подтверждена. `career.ozon.ru` проверен контрактами URL/транспорта, полноценный живой проход отдельно не выполнен.

## Настройки и фильтры 0.10.5

На сайте откройте **Настройки компаний**: редактируются Top Tier, 2nd Tier и Other Tier, название, варианты названий, адреса job boards и CSS-селекторы. Каталог хранится в SQLite с историей; конфликт сохранения из двух окон обнаруживается по версии. Первоначальный список содержит 33 компании. Кнопка **Настройки компаний, tiers и адаптеров** в шаге 2 расширения открывает тот же редактор. Новые настройки загружаются расширением при открытии поиска, рейтинга и перед сбором; последняя копия доступна при временной недоступности сервиса.

В архиве и рейтинге — чекбоксы нескольких компаний, поиск, быстрые наборы tiers, выбор всех и сброс. Ничего не выбрано означает пустую выдачу. Изменение фильтра не вызывает модель; при явном расчёте фильтр применяется до embedding-запросов. Лимит одного расчёта — 200 полных вакансий: более широкую подборку нужно сузить.

Ручные селекторы используются общим движком на конкретном настроенном сайте. Они не превращаются автоматически в проверенный адаптер или адаптер отправки. Требуется проверить полученный текст. Для неизвестных сайтов исправлено согласование URL-ID браузера с сервером.

**О сервисе** содержит руководство и объяснение компонентов. Раздел истории называется **История разборов вакансий (для выбранных CV)**.
