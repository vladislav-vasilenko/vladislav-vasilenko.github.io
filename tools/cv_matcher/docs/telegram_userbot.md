# Управляемый отклик: расширение + Telethon + управляющий Telegram-бот

Версия расширения: 0.9.0. Актуальный общий процесс: [CRM откликов](application_crm.md). Userbot подключается к вашему пользовательскому аккаунту
и только к `@giga_recruiter_bot`. Отдельный Bot API бот показывает вам вопросы и
редактируемые ответы. После генерации ответ сам не отправляется.

## Подключение

1. Создайте своего управляющего бота у @BotFather. Получите API ID/hash для
   пользовательского клиента на https://my.telegram.org/apps.
2. Добавьте поля из `telegram.env.example` в существующий локальный `.env`.
   `TELEGRAM_BOT_TOKEN` — токен вашего управляющего бота, `TELEGRAM_OWNER_ID` —
   ID того же аккаунта, который будет авторизован в Telethon. Ключ OpenAI остаётся
   в существующем `OPENAI_API_KEY`. Не перезаписывайте весь `.env` шаблоном.
3. В папке cv_matcher установите `uv sync --extra telegram` и выполните
   `.venv/bin/python telegram_recruiter.py --login`. Номер, код и пароль 2FA
   вводятся скрыто в вашем терминале. Сам вход не отправляет сообщений рекрутеру.
4. Запустите `.venv/bin/python resume_import_server.py` и в другом терминале
   `.venv/bin/python telegram_recruiter.py`. Откройте своего управляющего бота.
   Существующий webhook у него не удаляется: для long polling нужен отдельный бот.

## Цикл вопрос–ответ

В рейтинге расширения: «Откликнуться» → Telegram → «Создать отклик с выбранным CV».
Контекст выбранного CV, вакансии и цели сохраняется локально. В управляющем боте
отправьте `/applications` и выберите этот отклик. `/start_recruiter` явно отправит
`/start` в Giga; `/question` продолжит уже существующий диалог без его сброса.
Навигация по конкретной вакансии выполняется доступными кнопками рекрутера:
userbot не предполагает недокументированных deep links и не выбирает вакансию сам.

Вопрос от Giga → Luna / Terra / Sol → черновик + цитаты и уточнения →
«Отправить», «Редактировать» или «Свой ответ». После выбора редактирования отправьте
управляющему боту полный новый текст одним сообщением: он снова покажет его
с кнопкой отправки. Написанный текст не уходит рекрутеру до этой кнопки.
Если информации нет (например, зарплата), модель должна запросить уточнение;
кнопка отправки такого черновика недоступна до ручной правки.

Предыдущие отправленные ответы передаются модели для связности. Для кнопочных
вопросов управляющий бот показывает доступные текстовые/callback варианты.
Контакт, геолокацию, URL и WebApp обрабатывайте вручную в Telegram.
`/cancel` отменяет ввод; `/pause` освобождает диалог для другого отклика;
`/done` помечает отклик завершённым **вами**, без предположения об оффере/найме.

Модели: Luna `gpt-6-luna`, Terra `gpt-5.6-terra`, Sol `gpt-6.1-sol`.
Вызовы платные, только после выбора модели; повторный тот же контекст берётся
из приватного кэша. Доступ конкретного API-ключа к моделям проверяется при вызове.
Цитаты и проверка схемы не гарантируют смысловую достоверность: нужен ваш просмотр.

## HH и CRM

Откройте локальный сайт → Отклики; подключите выделенную HH-вкладку в popup расширения → Отклик. Письмо обсуждается и редактируется в карточке. Форма читается расширением, затем вы разрешаете ровно показанные CV, письмо и ответы. Изменения отзывают прежнее разрешение; подтверждение HH сохраняется в SQLite. Старый интерфейс расширения переводит отправку в общее рабочее место. Пошаговая инструкция — в [CRM откликов](application_crm.md).

Без Telethon используйте `telegram_recruiter.py --operator-only`: `/today`, `/hh`, `/sync_hh`. Этапы CRM меняются вручную на сайте или в Telegram и не затираются статусами HH. Расписание подборок — 10:00 и 19:00 по Москве, пока процессы и подключённый Chrome работают. Секреты остаются в `.env`.

## Состояние и границы проверки

SQLite `.cache/applications/state.sqlite3`, Telegram session `.cache/telegram`
и кэш `.cache/recruiter_answers` остаются локальными, каталоги 0700, файлы 0600.
Одновременно активен один диалог Giga. Изменившийся вопрос/кнопки блокируют старый
ответ, повторная отправка блокируется в SQLite. После сетевой неопределённости
проверяйте диалог вручную: автоматического повтора отправки нет.

Автотесты используют поддельные Telegram-транспорты и OpenAI; реальные сообщения
пользователям/ботам они не отправляют. Живой Telegram и отправка HH требуют
ваших учётных данных/форм и отдельно ещё не подтверждены. Селекторы HH могут
измениться; нераспознанная форма требует продолжения на сайте вручную.

Источники: [Telethon](https://docs.telethon.dev/en/stable/modules/client.html),
[Telegram API ID](https://core.telegram.org/api/obtaining_api_id),
[Bot API](https://core.telegram.org/bots/api).
