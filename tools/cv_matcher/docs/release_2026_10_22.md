# Срез реализации и документации — 22.10.2026

Это описание текущей совокупности функций, а не новый номер версии расширения. Исходники: Chrome 0.11.22, health 13, collection protocol 2.

## Изменения, отражённые в документации

- Гибридный Python/Chrome сбор, persistent backfill и прогресс; разгрузка local storage при подключённом архиве.
- Полноценный просмотр CV с потоками текстовых чанков и экспортом связей для LLM без API; отдельный разбор нескольких CV с дополнительными документами через Luna/Terra или импорт JSON.
- Карьерная траектория: цель, редактируемые этапы, критерии, evidence, варианты CV и связи/фильтры вакансий.
- GitHub collection: run history/control, отдельный импорт latest completed artifact, validation/freshness и checkpoints в локальной SQLite.
- Портфолио: Title/опыт основного HH-CV, проверенное введение RU/EN, исследования и разрешённая обезличенная визуальная выборка.
- Минималистичный обзор и полный CV на одном наборе данных, восемь оформлений, Telegram после Email, static EN/RU SEO и публичный PWA.
- Мобильное меню оформления закреплено относительно навигации и ограничено её шириной; внутренний scroll доступен при небольшой высоте.

## Проверено и не проверено

Последний полный изолированный backend-прогон после исправления экспорта GitHub: 478 Python tests; JS-контур: 385 tests. Повторно после mobile CSS: production build и 11 portfolio tests. Браузерная проверка раскрытого меню — восемь оформлений, 320/375/440 px, без горизонтального выхода за viewport. Реальный iPhone PWA install и живое редактирование LinkedIn этим не проверены.

Проверки не вызывали платные модели и не отправляли отклики. Число тестов и snapshot-счётчики не служат обещанием качества всего рынка или устойчивости любого внешнего DOM.

Обновление 23 октября: дата `last_updated` теперь отмечает запись JSON, а начало сбора хранится отдельно в `collection_started_at`. Иначе новые карточки, полученные после начала запуска, закономерно отклонялись импортом как будущие относительно выгрузки. Проверен round-trip производителя JSON и валидатора импорта.
