# Публичное портфолио: данные, визуализации и мобильная версия

Обновлено 25.10.2026. Сайт — отдельная публичная проекция локального Career Workspace. Контракт публикации: [GitHub + HH](github-import-and-portfolio.md). Корневой operational документ: [portfolio-publication.md](../../../../docs/portfolio-publication.md).

## Источники блоков

| Блок | Текущий источник | Ограничение |
|---|---|---|
| Title и опыт | Полный снимок основного HH-CV (`summary.primary_id`) | Не CV просто открытой карточки; ссылка на источник отображается |
| Введение под шапкой | HH About или проверенные локальные RU/EN-редакции | Редакция привязана к исходному CV/hash; не записывается обратно в HH |
| Образование | Контент портфолио | Автоматический перенос этого блока из HH ещё не реализован |
| Подтверждённые навыки | Owner-confirmed практика с проверенной публичной GitHub-ссылкой | URL не является аудитом кода; обучение не повышается до практики |
| Сейчас исследую | Выбранная для публикации траектория, до 5 тем и до 4 публичных лабораторий | Это развиваемые темы; блок отделён от практических подтверждений |
| Карта рынка | Выбранная обезличенная выборка, округлённые координаты и категории | Не полная картина рынка и не прогноз найма |
| Потоки выборки | Числа по специализациям и полноте текстов | Не личная воронка откликов |

Проекция формируется `portfolio_visuals.py`, сохраняется в `public/hh-experience.json`, проверяется frontend в `src/features/publicVisuals.ts`. Публичные блоки включаются в локальном UI отдельно после предпросмотра. Картинки из приватного интерфейса не публикуются автоматически.

## Что остаётся локально

SQLite, ключи и cookies, Candidate Facts/исходные трудовые документы, CRM и переписка, raw model reports, персональные проценты соответствия, идентификаторы вакансий в визуальной выборке и непроверенные цитаты. Автообновление включает только разрешённые поля проекции, а не все данные архива.

Практика, изучаемые темы и исследовательские ссылки визуально разделены. Краткий блок не должен собираться из обрывков/повторов модельных цитат. GitHub-проверка читает публичные metadata и несколько последних commits по запросу; непрерывного фонового аудита репозиториев пока нет.

## Представление

По умолчанию краткая страница; `?layout=full` раскрывает полное CV. Focus подсвечивает соответствующие фрагменты одного набора опыта. Восемь оформлений: Minimal, Macintosh ’84, OpenAI-inspired · Calm, Material 3 Expressive, Quiet Glass, Raw / Structural, Yandex-inspired, Sber-inspired. Calm объединён с OpenAI-inspired. Эти варианты не меняют факты и не заявляют аффилированность с брендами.

Telegram находится после Email в контактной строке и переносится вместе с контактами на узком экране. Меню оформления на ширине до 650 px привязано ко всей навигации, имеет ограниченную высоту и внутреннюю прокрутку. Анимация учитывает reduced motion.

В предпросмотре публикации доступен редактор перевода всех блоков опыта: компания, роль, даты, длительность и описание. Перевод сохраняется локально после отметки проверки, связан с ID основного HH-резюме и hash всей исходной истории. В публичную проекцию включаются только переводы текущего источника. ID блоков, даты и длительность проверяются сервером; соответствие формулировок проверяет владелец. При смене основного CV или текста опыта старый перевод отключается, и сайт показывает оригинал с отметкой ожидания перевода. Более старое отдельное EN-резюме не подменяет актуальное RU-резюме. Перевод введения RU/EN управляется отдельно. API модели при сохранении не вызывается; можно скопировать контекст для внешнего перевода.

Код: `src/portfolio_translations.py`, `portfolio_publication.py` и операция `save_experience_translation` в `/archive/portfolio-publication`. Текущий английский перевод включает 12 блоков основной RU-версии. Это редакция для портфолио, не запись обратно в HH. Изменённый Python-код подключается при следующем запуске локального сервиса.

Публичный мобильный номер скрыт в исходных копиях контента, печатном документе и экспортах. Локальное HH-резюме не меняется. В Intro, шапке и печатной версии есть Hugging Face. Кнопка «Резюме для печати» видна в Intro и навигации; `?print=true` открывает отдельный документ без 3D, а `?resumeView=true` — краткое резюме. Ссылка Intro всегда позволяет вернуться к анимации. Внешний HH-источник имеет прямую ссылку, английская история помечена «Translated from RU».

## Публикация, индексация и PWA

Сборка `npm run portfolio:build` выполняет TypeScript/Vite и статический prerender (`tools/portfolio-static.mjs`). GitHub Pages workflow публикует **dist**, не исходники main/root. Наличие коммита не доказывает deployment: проверить успешный Run и ответы сайта.

EN `/` и RU `/ru/` содержат читаемый HTML без JavaScript, canonical/hreflang, metadata, sitemap/robots и ProfilePage/Person. SPA-переключения используются поверх доступных HTML-страниц. Это техническая основа индексации; позиции Google/Yandex не гарантируются. Подтверждение собственности и отправка в панели вебмастеров — отдельные действия.

PWA manifest для каждого языка описывает одно приложение. Service worker кэширует только явный список публичных ресурсов; страницы и JSON — network-first с offline fallback, immutable assets — cache-first. Локальные API/SQLite/POST и произвольные адреса не кэшируются. После первой загрузки возможен offline просмотр последней сохранённой публичной версии. Установка зависит от возможностей браузера; уведомление об обновлении не прерывает чтение принудительно.

## Проверка

Portfolio tests проверяют escaping, HH title/введение, сохранение фактов между оформлениями, public visual contract, static EN/RU и изоляцию PWA cache. Проверка мобильного меню проведена в браузере на ширинах 320/375/440 px для восьми оформлений. Это не сертификация всех реальных iOS/Android устройств; установка PWA на физическом iPhone отдельно не проверена.
