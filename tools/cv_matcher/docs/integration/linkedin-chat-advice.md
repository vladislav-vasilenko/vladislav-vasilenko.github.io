# Анализ переписки и карьерные рекомендации

Обновлено 24.10.2026. Раздел LinkedIn → Чаты. Реализация: `src/linkedin_messages.py`, `src/linkedin_chat_analysis.py`, `archive-web/linkedin-chats.js`.

## Поток данных

1. Расширение прокручивает список вниз и открывает каждый выбранный диалог. Промежуточные карточки сразу сохраняются в SQLite.
2. Отдельная задача прокручивает историю вверх. Каждое сообщение хранит ID, автора, текст, наблюдаемое время, ссылки и бейджи. Повторные снимки объединяются, а не заменяют историю коротким превью.
3. В сервисе пользователь выбирает диалоги, резюме, цель, траекторию и число последних сообщений. API `prepare` фиксирует неизменяемый контекст с hashes источников. Обычный просмотр и подготовка не вызывают модель.
4. `prompt` возвращает полный запрос для буфера обмена без API. `import` проверяет вручную полученный JSON. `generate` требует явного подтверждения и использует выбранную настроенную модель.
5. Результат сохраняет приоритет, соответствие цели, сигнал интереса работодателя, стадию, цитаты, следующий шаг, вопросы и черновик ответа. Отправка сообщения отсутствует.

## Проверяемость и ограничения

- Каждая цитата должна буквально присутствовать в сообщении именно этого диалога. Выраженный интерес/отказ требует цитаты собеседника, а не соискателя.
- Приоритет не является вероятностью оффера. Семантическая близость, карьерный интерес и стадия общения оцениваются отдельно. При недостатке истории модель должна обозначать неопределённость.
- Дата наблюдения не превращается в дату сообщения. Достижение верхней границы означает границу доступной истории, а не доказательство полноты всей переписки LinkedIn.
- Платный запуск проверяет актуальность резюме, траектории и диалогов. После неопределённого сетевого результата автоматического повторного списания нет. Готовый ответ читается из кэша.
- Имена собеседников и private thread URL не включаются в идентификаторы промпта: используются T1/T1_M1. Email и телефоны скрываются. Остальной выбранный текст передаётся при API-подтверждении; пользователь видит состав и объём контекста.
- Контексты, сообщения, рекомендации и заметки локальные. Они не экспортируются в публичное портфолио, Actions или общий архив вакансий.

## API

`POST /archive/linkedin-chat-analysis`: `metadata`, `prepare`, `prompt`, `generate`, `import`. Используется существующая локальная UI-сессия либо сервисный код. Для `generate` нужно `confirmed=true`. Без действительного `context_key` результат не принимается.

Тесты используют искусственные сообщения и модель-заглушку. Платные вызовы, реальные сообщения и изменения контактов в тестах не выполняются.
