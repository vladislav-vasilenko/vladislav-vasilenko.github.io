# Компании, регионы и пакетный расчёт

Вакансии → Компании: отдельный селектор **Регион компаний**, затем флажки отдельных компаний или **Top Tier / 2nd Tier / Others**.

Регионы: RUS, US / UK / EU, China, JP, Australia / New Zealand, Другие. При выборе региона фильтруется и список доступных компаний, и сама выдача вакансий. Кнопка уровня выбирает компании этого уровня в текущем регионе. «Выбрать все» выбирает все компании текущего региона; «Все регионы» снимает региональное ограничение. «Сбросить» оставляет пустой выбор.

Регион и уровень — редактируемая классификация компании в Настройки → Компании и источники. Это не Locations вакансии и не ограничение страны трудоустройства. Фильтр JP или Australia / New Zealand может быть пустым, пока соответствующим компаниям не назначен этот регион. Нераспознанные названия из архива попадают в «Другие», их регион не выводится из текста вакансии автоматически.

Число рядом с компанией — количество сохранённых вакансий в локальной базе. Оно не равно числу карточек, замеченных парсером, и не означает полноту охвата компании. Другие фильтры (например, только полные описания) могут дополнительно уменьшить видимую выдачу.

Google и Meta доступны даже при старом сохранённом каталоге. Нулевой счётчик Meta до импорта новой выгрузки — отсутствие импортированных записей, а не подтверждение отсутствия вакансий на Meta Careers.

В разделе «Рейтинг по резюме» те же флажки задают компании для пакетной обработки уже загруженных полных описаний. Выберите CV и карьерную цель, подготовьте пакет и подтвердите расчёт через **text-embedding-3-small**. Шаг содержит до 20 вакансий; готовые векторы переиспользуются. Прогресс и пауза сохраняются в SQLite. Изменение фильтра само по себе не вызывает API.
