## Meta

Режим **«Meta · без лимита по числу вакансий»** включён по умолчанию для новых ручных настроек и расписания. Числовой лимит остальных источников не применяется к Meta в этом режиме; ограничение параллельных запросов сохраняется. CLI: `--meta-unlimited`, workflow input: `meta_unlimited=true`.

Текущий публичный GraphQL-контракт: `data.job_search_with_featured_jobs_v2.all_jobs`. Старый `job_search_with_featured_jobs.all_jobs` также поддержан. Раньше scraper пропускал v2 и записывал 0 карточек / 0 ошибок.

Добавлены актуальные `/profile/job_details/<id>/`, DOM fallback карточек и описаний, явные ошибки при нераспознанной выдаче/полных JD. В живой проверке получено **1 278** карточек и три полных описания с Locations. Run #184 успешно собрал и импортировал **500 полных описаний Meta**, 0 отклонений при импорте. Режим без лимита запущен отдельно (#185). Число вакансий — наблюдение конкретного запуска, а не постоянная характеристика источника.

## Locations

Сохраняется список явных локаций и отдельно обнаруженный формат remote/hybrid/onsite. Дубликаты нормализуются, отсутствующие локации помечаются `missing`, неполные списки могут иметь статус `partial`. Короткая карточка без локации не стирает прежние данные. Google и Meta передают структурированные списки, HH и остальные DOM-адаптеры читают доступные адресные/JobPosting поля.

## Компании и пакетный расчёт

Добавлен отдельный региональный фильтр: RUS, US / UK / EU, China, JP, Australia / New Zealand, Другие. Пресеты Top Tier / 2nd Tier / Others учитывают регион. Региональная классификация редактируется в настройках компании и не подменяет Locations вакансии. См. [пользовательский путь](usage/company-filter.md).

Google и Meta добавлены в каталог и доступные флажки компаний, включая ранее сохранённый пользовательский каталог. В «Рейтинг по резюме» доступен предпросмотр пакетного расчёта уже загруженных полных вакансий выбранных компаний.

Используется **text-embedding-3-small**. Это embedding-модель, а не генеративная GPT. Размер шага — до 20 вакансий, API получает до 64 текстовых фрагментов за запрос. Готовые векторы переиспользуются; сравнение учитывает конкретное резюме, карьерную цель и версию текста. Прогресс, пауза после текущей порции и явное продолжение сохраняются в SQLite. Изменение CV/вакансии останавливает пакет для новой сверки.

Платный расчёт не запускался при проверке: тест на 205 вакансиях использовал подставной backend.
