# Идея: восстановление DOM-адаптеров с помощью Luna

> Сверка 22.10.2026. Предложение не реализовано. Основной путь восстановления остаётся проверенным кодом adapter; для LinkedIn сначала нужны живые fixtures и [контракт capability](../integration/linkedin-adapters.md).

Статус на 22.10.2026: идея и требования; автоматические платные вызовы и активация сгенерированных адаптеров **не реализованы**.

## Назначение

Если сайт доступен и показывает нужные данные, но проверенный адаптер перестал извлекать их, предложить новые селекторы и пути чтения. Не использовать LLM для обхода CAPTCHA, входа, ограничений доступа, сетевых ошибок или переполнения хранилища.

## Входные данные

Передавать только ограниченный очищенный DOM области вакансии/выдачи: публичные названия, описания, структуру, data-qa, itemprop, role и ссылки на вакансии. Удалять формы, значения полей, cookies, токены, скрипты, переписку, контакты кандидата и внедрённые виджеты расширения. Отдельно передавать ожидаемый тип страницы и схему результата.

## Выход и локальная проверка

Модель возвращает декларативный JSON: селекторы полей и ограниченные операции чтения (выбрать элементы, извлечь текст/ссылку, перейти по проверенной ссылке следующей страницы). Не исполнять JavaScript/Python модели, evaluate, shell или произвольные сетевые запросы.

Проверять допустимые операции, домен и тип страницы, ID вакансии, число совпадений, видимость текста, полноту описания, согласованность заголовка и отсутствие примеси меню, формы отклика и рекламы. Пустой результат не подтверждает закрытие вакансии. Пагинация сохраняет исходные фильтры и имеет ограничения на страницы, записи и время.

## Хранение и жизненный цикл

Использовать существующий каталог адаптеров и проверить его возможности перед введением новой таблицы. Для кандидата адаптера хранить домен, тип страницы, версию схемы, структурный fingerprint, версию адаптера, источник правила, модель, время проверки, результаты тестов, утверждённый статус и предыдущую версию для отката.

Сначала shadow/dry-run на нескольких известных страницах, затем проверка человеком и активация. Сохранять последнюю исправную версию. При дрейфе структуры отключать несовместимое правило и показывать причину. Не генерировать новое правило на каждый отдельный сбой.

## Стоимость

По умолчанию — экспорт очищенного запроса без API. Для Luna через API показывать предварительный объём, лимит расходов и запрашивать предусмотренное пользователем согласование. Кэшировать результат по домену, типу страницы и fingerprint. Ввести лимит попыток восстановления и cooldown на источник. Этот контур отделён от рейтинга и анализа навыков.
