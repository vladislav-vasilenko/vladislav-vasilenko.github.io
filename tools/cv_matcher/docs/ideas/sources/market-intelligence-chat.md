# Идеи обзора рынка из обсуждения

Источник: сообщение пользователя в текущем чате, 20.10.2026. Ниже тематическая выжимка, **не дословная копия**. Статус: предложения для будущего плана, не описание реализованного функционала.

- «Око Саурона»: наблюдение за покрытым сегментом рынка, единая выдача из разных источников, дубли/репосты, спрос на компетенции и сигналы формирования исследовательских команд.
- Персональный рекрутер: отличать релевантность текущему CV от движения к желаемой роли. Для пользователя особенно интересны LLM Pretraining, Post-training/RL, Generative Models/Diffusion/DiT/Flow Matching и обучение моделей; обычный RAG/backend имеет иную карьерную ценность.
- Сквозной цикл: Discovery → Deduplication → Filtering → Ranking → CV Tailoring → Application Drafting → Tracking → Feedback. Отправка остаётся под контролем владельца.
- Вопросы системы: какие компании нанимают для pretraining, как меняется спрос на distributed training/RAG, какие компетенции нужно подтвердить, какие роли полезнее по задачам/условиям/перспективам интервью.
- Feedback из реальных откликов и интервью: причины отказов, качество версий CV, связь с требованиями. Не считать неизвестную причину доказанным skill gap.
- Метрики: Precision@20, discovery latency, time-to-application, interview conversion.
- Концепция полезности: `Score(v) = Fit(v) × CareerValue(v) × P(Interview | v, CV)`. Это предложенная схема, не готовая откалиброванная вероятностная модель.

При интерпретации учитывать охват источников, задержки ответов и отсутствие зарплат/результатов. Реалистичность вероятностного прогноза требует отдельного набора исходов и проверки калибровки. См. [индекс](../README.md).
