# Начало работы с Career Workspace

Актуально для исходников 24.10.2026; текущие версии расширения, health и протокола — в [README](README.md). Веб-сервис: <http://127.0.0.1:8788/>. Локальный архив сохраняет данные между запусками.

## 1. Запуск и подключение

Из корня репозитория:

```sh
npm run career:dev
```

На новом компьютере предварительно установить зависимости из `tools/cv_matcher/pyproject.toml` через `uv sync`. Chrome-расширение загружается из `tools/cv_matcher/hh-research-extension`. После обновления кода перезагрузить его на `chrome://extensions` и проверить соединение в параметрах расширения.

Код подключения находится локально в `.cache/resume_import/token.txt` относительно `tools/cv_matcher`. Ввести его в настройках расширения и открыть локальный сайт через кнопку подключения. Не копировать код в публичные issue или документацию. Ссылка подключения одноразовая; после перезапуска сервиса может потребоваться новое открытие из расширения.

## 2. Резюме и источники

В расширении собрать доступные собственные HH-резюме; сервис сохраняет снимки. В разделе «Резюме» выбрать **основное** CV — именно оно служит источником публикации портфолио. Просто открытая карточка не меняет основное резюме.

Файлы и Google Docs импортируются с предпросмотром. Для сравнения можно добавить отдельные профессиональные источники: выписки, даты, заметки и фрагменты других CV. Они не становятся подтверждёнными фактами автоматически. Поддержка форматов, лимиты и ограничения OCR: [портфельный разбор](architecture/resume-portfolio-review.md).

## 3. Цель и траектория

Открыть **«Карьерная траектория»** (`?view=learning`), выбрать профиль и отредактировать цель, этапы, обязательные и дополнительные критерии. Уже созданный путь редактируется кнопкой «Редактировать цель и этапы», без создания нового.

Привязать имеющиеся проекты, исследования и опыт к критериям. Практика и обучение различаются. Внутри этапа доступны вакансии, выбор CV и приоритеты навыков. Для создания цели CV не обязателен. [Подробности](architecture/career-trajectory.md).

## 4. Вакансии и полные описания

Выбрать источники, фильтры и порядок Python/Chrome в настройках сбора. HH требует активного Chrome; Google/Meta — Python; для поддержанных компаний есть гибридный fallback. Запустить поиск и следить за общей задачей.

В «Вакансиях» доступны фильтры по траектории, пересечениям и отсутствию связи. Полные описания можно дозагрузить отдельной очередью. Карточка, ошибка и закрытая вакансия — разные состояния. Сбор не считается полным только потому, что задача остановилась.

GitHub Actions управляется из панели «GitHub Actions · импорт вакансий»: история, запуск/остановка сборщика и импорт результатов. Облачный запуск и перенос в локальный архив — отдельные операции. [Инструкция](integration/github-import-and-portfolio.md).

## 5. Анализ и выбор резюме

- **Локально:** документное сравнение, текстовый diff, потоки чанков, подсветка упоминаний и планы навыков.
- **Без API модели:** подробный промпт со снимками, источниками и связями; ручное обсуждение в своём LLM-чате, затем проверяемый импорт результата.
- **Через API:** явный запуск embeddings или разбора Luna/Terra с выбранным контекстом. Просмотр сохранённого результата сам по себе не платный.

Семантическая близость не является процентом квалификации. Отсутствие упоминания в CV означает необходимость уточнения, а не доказанный пробел. [Сравнение CV](integration/resume-comparison.md).

## 6. Подготовка отклика

В карточке вакансии подготовить кейс, письмо и данные формы. Проверить источники, факты и текст. HH-исполнение связано с конкретным разрешением; корпоративные формы имеют свои ограничения. Ручная отметка «Отклик сделан» не равна квитанции отправки. [CRM](application_crm.md).

## 7. Обновление портфолио

**Резюме → Портфолио · введение, опыт HH и GitHub**: проверить Title/опыт из основного HH-CV, отредактировать введение RU/EN, выбрать публичные блоки, просмотреть JSON и опубликовать. Автообновление включается отдельно и работает при запущенном сервисе.

Внешний сайт получает разрешённую JSON-проекцию; SQLite и личная история откликов остаются локально. LinkedIn пока не синхронизируется: [следующий этап](integration/linkedin-adapters.md).

Если что-то не работает, начать с [диагностики](operations.md), не удаляя архив и данные расширения.
