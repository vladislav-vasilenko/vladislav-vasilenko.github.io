Код подключения и запуск сервиса

В папке cv_matcher запустите сервис. Локальный код находится в .cache/resume_import/token.txt. Ключ OpenAI хранится отдельно в .env.

.venv/bin/python resume_import_server.py

Сохраняется код доступа к локальному сервису. Без этой галочки после перезапуска Chrome может потребоваться повторное подключение.

После вашего разрешения расширение откроет служебную вкладку HH и будет использовать её для задач сайта и Telegram.

Что разрешается расширению

Доступ только к hh.ru: проверять активность, читать страницы и форму отклика, переносить письмо. Генерация через API запускается отдельно. Отправка отклика требует вашего разрешения для конкретных CV, письма и ответов.

Карьерные сайты · чтение вакансий и анкет

Разрешение позволяет Chrome читать вакансии Avito, Ozon, Yandex, Sber и T-Bank в отдельных служебных вкладках. Оно нужно и для открытия анкет из веб-сервиса. Перенос проверенных полей требует отдельного разрешения; отправка откликов этим доступом не разрешается. Адреса выдачи и режим API задаются на рабочем сайте → Сегодня → Поиск по расписанию.
