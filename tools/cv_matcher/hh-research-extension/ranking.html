Рейтинг вакансий по выбранному резюме

Сравниваются полные сохранённые описания. При смене резюме рейтинг нужно пересчитать. Модель не проверяет достоверность опыта и не оценивает вероятность найма.

В сервис уходит только выбранное CV и вакансии этой компании. Готовые сравнения и векторы берутся из кэша; новые embeddings рассчитываются только для отсутствующих фрагментов.

Без цели — близость к выбранному CV. С целью — 80% CV + 20% цель. Вес — начальная эвристика.

Подключение локального сервиса

В папке cv_matcher запустите .venv/bin/python resume_import_server.py. Ключ OpenAI задаётся только в .env этой папки как OPENAI_API_KEY=…. Код подключения лежит в .cache/resume_import/token.txt.

По кнопке ниже выбранный профессиональный текст CV, цель и описания вакансий отправляются в OpenAI API через ваш локальный сервис. Ключ в расширение не передаётся. Неизменившиеся фрагменты берутся из локального кэша.

Количество показанных результатов можно менять после расчёта. Новых запросов к OpenAI это не вызывает.

В каждой карточке есть «Сопроводительный текст»: письмо на 1–50 предложений по выбранному CV и полной вакансии. По кнопке — до двух запросов OpenAI с одной попыткой исправления; повтор готового текста берётся из кэша.

«Скопировать CV + вакансию для ChatGPT» готовит пакет с промптом для сравнения навыков и дальнейшего обсуждения вопросов рекрутера. Копирование не вызывает API.
